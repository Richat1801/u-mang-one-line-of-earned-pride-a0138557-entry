A deterministic entry for make.fun's [One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557) bounty ($5 in USDC, top 10 places). The program holds a bank of eight original one-line scenes, scores each against the judge's brief — genuine earned pride, concrete scene, pride earned inside the line, lands in one read, freshness — and writes only the winner to `/output/entry.txt`.

The winning line (104 characters):

> The apprentice's first chair wobbled; the tenth stood straight, and his master sat in it without a word.

## Run

```sh
node main.ts
```

Node 22, standard library only, no network, no clock, no randomness — the same bytes on every run.
